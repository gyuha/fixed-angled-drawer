# 실행 기록 — 적층형 경사 필통 FreeCAD 모델링

## 조각별 결과
- S1 참고 STL 실측 (벽 3mm·바닥/선반 4mm·경사 20°·앞면 밴드+립 구조·선반 아래 중공 쐐기) — ✅ 계획대로
- S2 적층 모듈 모델링 — ⚠ 참고 모델의 상단 라운드(필렛)는 스냅 인터페이스 단순화를 위해 생략
- S3 1단(클램프+암나사) 모델링 — ⚠ 검증 방법 교체 (OCC BoundBox 과대추정 → 테셀레이션 실측)
- S4 썸스크류 모델링 — ⚠ 나사산 클리핑 우회 (common() 실패 → 끝단을 재료 속에 묻는 배치)
- S5 FCStd + 바이너리 STL 3개 내보내기, 검증 9항목 PASS — ⚠ exportStl이 ASCII로 출력되어 MeshPart 바이너리 내보내기로 교체

## 계획대로 된 것
- 3개 부품(module / tier1 / thumbscrew) 모두 유효 솔리드로 생성, 외형 치수 요구 사양과 일치 (module 80×100×170 + 스커트 12, tier1 개구 40mm, 나사 OD 18.5·피치 4·나사부 22).
- 단면 시각 점검으로 형상 확인: 선반 앞-높음/뒤-낮음 20° 경사, 앞턱, 중공 쐐기, ㄷ자 클램프, 암나사 홈 모두 의도대로.
- 파라메트릭: 모든 치수가 스크립트 상단 PARAMS 상수(실측 근거 주석 포함)로 노출됨.

## 현장 결정 (계획에 없던 판단)
- 모든 칸에 앞턱(립) 6mm 통일 적용 — 참고 모델은 최하단만 밴드였으나, 물건 미끄럼 방지 목적의 기능 개선. 파라미터 `LIP`로 조정 가능.
- 상단 라운드(필렛) 생략 — 참고 모델의 곡면 마감은 미관용이고, 스냅 캐치 창이 있는 상단 테두리를 평면으로 유지하는 편이 결합 강성과 불리언 안정성에 유리.
- 스냅 돌기는 모듈 발자국(80mm) 안쪽으로 돌출하도록 설계 — 외형 치수가 커지지 않음.

## 막혔던 곳 / 학습
1. **`removeSplitter()`가 헬리컬 스윕이 포함된 솔리드를 invalid로 만든다** (FreeCAD 1.1.3). 미관용 호출이라 전부 제거로 해결.
2. **`Shape.common()` 클리핑이 헬리컬 파이프셸 솔리드에 조용히 실패한다** — 결과가 잘리지 않은 채 반환됨. 나사산 양 끝의 프로파일 돌출(±1.4~1.6mm)을 손잡이·턱 재료 속에 묻는 배치로 우회.
3. **OCC `BoundBox`는 트림 전 곡면 제어점 기준의 과대 추정** — 헬리컬 절삭 후 bbox가 실제보다 2.6mm 크게 나옴. 치수 검증은 `tessellate()` 기반 실측 bbox(`TightBB`)로 해야 정확.
4. **`Shape.exportStl()`은 ASCII STL을 쓴다** — 헬리컬 부품이 8.6MB로 비대. `MeshPart.meshFromShape` + `mesh.write()`로 바이너리 출력 (138KB).

## 프린트 참고 (검증 범위 외 권고)
- module: 뒷면을 베드에 대고 출력 권장 (경사 선반이 70° 벽이 되어 서포트 최소화).
- tier1: 클램프 뒷판 때문에 뒷면 안착 불가 — 앞면을 베드에 대는 방향 권장.
- 스냅 공차(CLEAR=0.25)·나사 공차(THR_CLEAR=0.4)는 프린터에 따라 첫 시험 인쇄 후 조정.
