# 1단 서랍 변형(tier1-drawer)과 서랍 부품 추가

## 목표 / 비목표
- 목표: 기존 `tier1`을 그대로 남긴 채, 최하단 칸을 사각 서랍 구간으로 바꾼 변형 `tier1-drawer`와 그 안에 끼우는 별도 부품 `drawer`를 생성한다. 두 부품 모두 STL로 내보내고, 서랍이 실제로 들어가고 빠지는지를 검증 항목으로 판정한다.
- 비목표: 기존 tier1 형상 변경, module2·module3·topmodule·lid·thumbscrew 변경, 슬라이드 레일·스토퍼·손잡이 별도 부품, 서랍 내부 칸막이, 서랍이 빠지지 않게 막는 장치(뒷부분 이탈 방지 툴은 "당기면 완전히 빠진다"는 결정과 상충하므로 넣지 않음).

## 확정 사양 (그릴링 합의)
- **대상 칸**: tier1의 **최하단 칸 1개**(경사 선반 + 그 아래 포켓)를 통째로 서랍 구간으로 대체. 위 2칸은 기존 경사 칸 그대로. 외형·클램프·상단 캐치·스냅 인터페이스는 tier1과 동일.
- **서랍 형태**: **쐐기 서랍** — 경사 천장을 따라가 앞이 높고(87.5mm) 뒤가 낮다(52.9mm). 천장과 서랍 상면의 기울기가 같아 인출·삽입 중 간섭이 없다(빼면 여유가 오히려 늘어난다). 별도 천장판은 두지 않는다 — 경사 공간을 서랍이 직접 쓴다. 내부 용적 약 350cm³ (사각안 대비 +30%).
- **앞판**: **플러시 인셋 + 개구 전체 높이 커버**. 앞판이 바닥부터 천장까지(z 4~91.5) 개구를 덮어 안쪽을 최대로 쓴다. 밀어 넣으면 뒷벽 2mm 앞에서 멈추고, 당기면 완전히 빠진다.
- **손가락 개구**: 앞판의 **가로 타원 관통구 30×16mm**, 위치는 **빈 서랍의 실제 무게중심 높이**(솔리드에서 계산, 현재 z=29.0). 당김점·무게중심·레일이 한 선에 놓여 기울임 모멘트가 0이 된다. 형상이 바뀌면 자동으로 따라온다. **개구 모서리는 앞뒤 양면 r1.0으로 굴린다** — 3mm 판을 그냥 뚫으면 손가락이 걸리는 각진 모서리가 살을 파고든다. (돌출 손잡이는 채택하지 않음: 필요 당김력이 1.6~5N에 불과해 그립력 이점이 없고, 앞으로 튀어나온 형상은 바닥 안착 출력에서 오버행이 되어 서포트 0을 깨며, 전 부품 플러시 디자인과 어긋난다.)
- **가드 레일**: **홈은 서랍 측벽, 리브는 본체 측벽**(서랍이 파이는 쪽). 홈 1.4깊이 × 3.0높이 / 리브 1.0돌출 × 2.4높이 → 상하 각 0.30 · 깊이 0.40mm 여유. **레일은 앞면까지 나오지 않는다** — 깊이의 앞 1/5(19mm)을 비우고 **4/5 구간만** 안내한다(`RAIL_START=0.2`). 76mm까지 안내되다가 그 이상 빼면 리브가 홈 뒤끝으로 빠져 분리된다. 홈 뒤 서랍 벽은 안쪽 보강 패드로 두께를 2.1mm로 회복한다.
- **타공**: 서랍 자체는 전면 타공 없음. **본체도 서랍 구간에서는 타공 제외**(서랍이 닿는 면이라 걸림·먼지 방지). 위 2칸 구간의 타공은 유지.
- **공차 (파라미터)**: 서랍 좌우 각 0.4mm, 상하 합 0.5mm, 깊이 뒷벽 앞 2mm 여유. **레일 공차 `RAIL_CLEAR` — 상하 각 0.3mm·깊이 0.4mm.** 서랍 벽 2.5mm·바닥 3mm·앞판 3mm 권장. 레일은 공차에 민감해 첫 출력에서 빡빡하거나 헐거우면 이 값을 조정해 재출력한다.
- **출력 방향**: 본체는 기존과 동일하게 뒷면을 베드에. 서랍은 바닥을 베드에(위가 열려 서포트 불필요).
- **회고 반영**(`.forge/retro/260818-133530-*`): 치수 검증만으로는 "쓸 수 있는지"를 못 잡는다 → 아래 DoD에 **끼움·공차·홈 크기**를 계산 판정 항목으로 넣는다. 헬리컬 솔리드가 아니므로 OCC 필렛·불리언 제약은 이번 작업엔 해당 없음.

## 진실의 원천
- 용어: `.forge/CONTEXT.md`의 서랍 구간 · 서랍 · 1단 · 경사 칸 · 앞턱
- 관련 ADR: 없음 (되돌리기 어려운 결정 없음 — 형태 선택은 파라미터/형상 수정으로 되돌릴 수 있음)
- 완료 정의(DoD): `freecadcmd pen_holder.py` 실행 시 `output/tier1-drawer.stl`·`output/drawer.stl`이 생성되고, 검증에서 (a) 두 부품 모두 유효 솔리드, (b) 서랍이 구간에 좌우 각 0.4·상하 0.5mm 여유로 들어가고 쐐기 기울기가 천장과 일치, (c) 밀어 넣으면 뒷벽 앞에서 멈춤, (d) 손가락 개구 30×16mm이고 중심이 빈 서랍 무게중심 높이, (e) 서랍 구간 본체 측벽과 서랍의 타공 수가 0, (f) 레일 끼움(상하 각 0.3·깊이 0.4mm 여유, 홈 뒤 벽 ≥1.5mm)과 레일 구간(앞면 노출 없음, 깊이의 4/5 안내) — 이 항목들이 모두 PASS로 출력된다.

## 작업 조각
- [ ] S1. `tier1-drawer` 본체 — 최하단 칸의 경사 선반·앞턱·하단 포켓을 제거해 바닥~경사 천장을 통째로 서랍 구간으로 열고, 측벽에 레일 리브를 붙이고 구간 타공 제외. 위 2칸·클램프·상단 캐치는 tier1과 동일 — 완료 기준: 유효 솔리드이고 서랍 구간이 바닥~경사 천장까지 열려 있으며, 양 측벽 리브가 앞에서 19mm 들어간 지점부터 있고 그 구간 타공 수 0
- [ ] S2. `drawer` 부품 — 쐐기 상자(위 개방·타공 없음) + 전체 높이 앞판 + 무게중심 높이의 타원 개구 + 양 측벽 레일 홈(앞 1/5 비움) + 홈 보강 패드 — 완료 기준: 유효 솔리드, 개구 30×16mm이고 중심이 무게중심 높이, 홈이 본체 리브와 공차 내로 물림 (depends: S1)
- [ ] S3. 끼움 검증 항목 추가(서랍 공차·레일 공차·깊이 정지·타공 0) + FCStd 배치(부품 나열 + 서랍을 빼낸 분해 뷰) + STL 2개 내보내기 — 완료 기준: DoD 다섯 항목 전부 PASS 출력, 스크린샷 재생성 (depends: S1, S2)
