# 실행 기록 — 1단 서랍 변형(tier1-drawer)과 서랍 부품 추가

> 1차 실행(사각 서랍) 후 요구가 바뀌어 계획을 갱신하고 **재실행**한 기록이다.
> 변경 3건: 쐐기 서랍으로 경사 공간 사용 · 레일 역할 교체(홈=서랍) · 레일을 앞면까지 내지 않고 깊이의 4/5만.

## 조각별 결과
- S1 `tier1-drawer` 본체 (바닥~경사 천장 통째 개방 + 측벽 리브 + 구간 타공 제외) — ✅ 계획대로
- S2 `drawer` 부품 (쐐기 상자 + 전체 높이 앞판 + 무게중심 높이 타원 개구 + 개구 모서리 r1.0 + 홈·보강 패드) — ✅ 계획대로
- S3 검증 항목 확장 + FCStd 배치 + STL 내보내기 — ⚠ `Part.Compound`에 `CenterOfMass`가 없어 `Solids[0]`에서 구해야 했음

## 계획대로 된 것
- 기존 `tier1`은 여전히 형상 변화 없음(변형은 `make_tier1(drawer=True)` 인자 분기). 부품 8종 모두 유효 솔리드, 검증 30항목 PASS.
- 쐐기 서랍: 63.2 × 95mm, 앞 높이 **87.5mm** → 뒤 **52.9mm**. STL 실측으로 상면 기울기가 천장과 동일함을 확인(y=0에서 87.5, y=95에서 52.9). 기울기가 같아 인출·삽입 중 간섭이 없고, 빼낼수록 여유가 늘어난다.
- 앞판이 개구 전체(z 4~91.5)를 덮어 안쪽을 최대로 쓴다. 내부 용적 약 **350cm³** (사각안 대비 +30% 남짓).
- 레일 역할 교체 확인: 서랍 측벽에 홈(module z 31.5~34.5), 본체 측벽에 리브(31.78~34.18) → 리브가 홈 안에 아래 0.28 · 위 0.32mm 여유로 물린다.
- 레일 구간: 홈·리브 **모두 y=19mm(깊이의 1/5)부터** 시작해 앞면에 드러나지 않는다(STL 실측). 깊이의 4/5가 안내되어 **76mm 인출까지 처짐 없이** 지지되고, 그 이상 빼면 리브가 홈 뒤끝으로 빠져 분리된다.
- 타공: 서랍 구간(경사 천장 아래) 본체 0개 · 서랍 0개.

## 현장 결정 (계획에 없던 판단)
- **손가락 개구 높이를 고정값이 아니라 솔리드의 무게중심에서 계산**하도록 바꿨다. 쐐기 형상은 기하 중앙(43.8mm)과 무게중심(29.0mm)이 크게 다르므로, 중앙에 두면 애초의 의도(무게중심에서 당겨 모멘트 0)가 깨진다. `CenterOfMass`로 구해 개구와 레일을 같은 높이에 두었고, 형상이 바뀌면 자동으로 따라온다.
- 천장판 파라미터(`DRAWER_CEIL_T`)를 삭제했다 — 쐐기 서랍이 경사 공간을 직접 쓰므로 천장판이 오히려 공간을 막는다.
- 타공 회피를 "특정 높이 아래 제외"에서 **"경사 천장 아래 전체 제외"(구멍별 판정)** 로 바꿨다. 서랍 구간이 이제 경사면이라 단순 높이 기준으로는 맞지 않는다.
- 홈을 판 뒤 서랍 벽이 1.1mm로 얇아지므로, 홈 뒤쪽에만 안쪽 보강 패드(1.0mm)를 덧대 2.1mm를 회복했다. 내부 용적 손실은 3mm 띠뿐이다.

- **손잡이 대신 구멍을 유지하고 모서리만 굴렸다.** 돌출 손잡이를 검토했으나 (1) 필요 당김력이 400g 기준 1.6N, 뻑뻑해도 5N 수준이라 손가락 하나로 충분하고 (2) 앞으로 돌출한 형상은 바닥 안착 출력에서 오버행이 되어 이 프로젝트의 서포트 0을 깨며 (3) 전 부품 플러시 디자인과 어긋나 채택하지 않았다. 대신 실제로 힘이 걸리는 개구 모서리를 앞뒤 양면 r1.0으로 굴려 손가락 압박만 덜었다(STL에서 곡면 확인).

## 막혔던 곳 / 학습
1. **`Part.Compound`에는 `CenterOfMass`가 없다.** 불리언 결과가 컴파운드로 감싸져 나오므로 `shape.Solids[0].CenterOfMass`로 접근해야 한다. FreeCAD의 형상 타입이 연산에 따라 바뀐다는 점을 매번 의식해야 한다.
2. **형상을 바꾸면 "중앙"의 의미가 바뀐다.** 사각 서랍에서는 기하 중앙 = 무게중심이었지만 쐐기에서는 14mm 차이가 난다. 치수를 상수로 박아두면 이런 변경에서 조용히 의도를 잃는다 — 계산으로 유도되게 두는 편이 안전하다.

## 다음 단계 (검증 범위 외)
- 실제 출력에서 서랍 미끄러짐은 프린터 공차에 달렸다. 빡빡하면 `RAIL_GROOVE_H`/`RAIL_GROOVE_D`를 키우거나 `DRAWER_CLEAR`를 0.5로, 헐거우면 반대로 조정해 서랍만 재출력하면 된다.
- 출력 방향: 본체는 뒷면을 베드에, 서랍은 바닥을 베드에(위 개방·상면 경사 모두 서포트 불필요).
