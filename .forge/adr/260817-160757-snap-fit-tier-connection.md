# 단간 연결 방식으로 스냅핏 클립 채택 (도브테일 대신)

## 맥락
적층형 경사 필통은 모듈을 계속 쌓아 올리는 구조라, 단 사이 연결 인터페이스는 모든 모듈이 공유한다. 한 번 프린트한 뒤 인터페이스를 바꾸면 기존 모듈 전부를 재출력해야 하므로 되돌리기 비용이 크다. 후보는 립&리세스(얹기), 도브테일 슬라이드, 스냅핏 클립이었고, "높이 올려도 흔들리지 않게"라는 요구 기준으로 시각 컴패니언 단면도 비교를 거쳤다.

## 결정
스냅핏 클립을 채택한다 — 위 모듈 바닥의 일체형 후크가 아래 모듈 상단 캐치 구멍에 눌러 끼워져 고정된다. 에이전트 권장안은 도브테일 슬라이드(수직·수평 모두 잠기고 마모 없음)였으나, 사용자가 조립 편의(위에서 눌러 딸깍)를 우선해 스냅핏을 선택했다.

## 트레이드오프
- 얻는 것: 위에서 눌러 끼우는 직관적 조립, 수직 방향 잠금(들어도 안 빠짐), 슬라이드 공간 불필요.
- 감수하는 것: 반복 분해 시 후크 마모·파손 위험, 후크가 프린트 방향(레이어 접착)에 민감함. 완화책으로 후크를 본체 일체형으로 두껍게 설계하고 공차를 파라미터화한다.
