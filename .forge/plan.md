# 적층형 경사 필통 FreeCAD 모델링

## 목표 / 비목표
- 목표: 파라메트릭 FreeCAD Python 스크립트 하나로 3개 부품(1단 클램프형 필통, 적층 모듈, 썸스크류)을 생성하고 FCStd + 부품별 STL로 내보낸다. 모든 치수는 스크립트 상단 파라미터로 조정 가능해야 한다.
- 비목표: 슬라이싱/프린트 프로파일, 조립 설명서, 도브테일 등 다른 연결 방식 변형, 3칸 변형 모델, 업로드된 참고 클램프 부품의 재현.

## 확정 사양 (그릴링 합의)
- **모듈 외형**: 폭 80 × 깊이 100 × 높이 170mm (후크·클램프 돌출 제외). 경사 칸 2개, 칸 피치 85mm.
- **경사각**: 수평 대비 20° — 참고 STL(`reference/pen-holder-reference.stl`) 법선 실측값.
- **단간 연결**: 스냅핏 클립 — 위 모듈 바닥의 후크가 아래 모듈 상단의 캐치 구멍에 딸깍 고정. 모든 모듈(1단 포함)의 상단 캐치는 동일 형상 → 어느 모듈이든 최상단이 될 수 있고 같은 모듈을 무한 적층. 반복 분해 마모를 고려해 후크는 본체 일체형으로 두껍게. 결정 근거: `.forge/adr/260817-160757-snap-fit-tier-connection.md`
- **1단 고정**: 뒷면 일체형 ㄷ자 책상 모서리 클램프. 개구(상판 물림) 40mm — 상판 18~25mm + 조임 여유. 아래턱에 암나사.
- **나사 규격** (업로드 썸스크류 실측, 호환 유지): 외경 18.5mm / 골지름 12.7mm / 피치 4mm / 나사부 길이 22mm / 손잡이 Ø32.6×10mm. 새 썸스크류도 이 규격으로 모델링 — 사용자의 기존 나사(`reference/thumbscrew-reference.stl`)를 그대로 끼울 수 있어야 한다.
- **공차 (파라미터 기본값)**: 스냅핏 0.25mm, 암나사 반경 방향 0.4~0.5mm.
- **벽 두께 등 세부 형상**: 참고 STL에서 실측해 채택 (S1에서 확정).
- **검증 환경**: `/Applications/FreeCAD.app` 설치 확인됨 — headless 실행으로 검증.

## 진실의 원천
- 용어: `.forge/CONTEXT.md`의 적층 모듈 · 1단 · 스냅핏 클립 · 경사 칸 · 클램프 · 썸스크류
- 관련 ADR: `.forge/adr/260817-160757-snap-fit-tier-connection.md`
- 완료 정의(DoD): 저장소에 파라메트릭 스크립트 + FCStd + STL 3개(`tier1.stl`, `module.stl`, `thumbscrew.stl`)가 생성되고, headless 검증이 (a) 3개 부품 모두 유효 솔리드, (b) 모듈 바운딩박스 80×100×170mm(돌출 제외) 일치, (c) 나사-암나사 치수 정합(공차 포함)을 통과 출력한다.

## 작업 조각
- [ ] S1. 참고 STL 실측 상세화 — 벽 두께, 앞벽(입술) 높이, 바닥 두께, 상단 라운드 반경을 `reference/pen-holder-reference.stl`에서 측정해 파라미터 표 확정 — 완료 기준: 스크립트 상단 PARAMS에 실측 근거 주석과 함께 기록됨
- [ ] S2. 적층 모듈 모델링 — 경사 2칸(20°) 본체 + 상단 캐치 + 바닥 스냅 후크 — 완료 기준: headless 실행 시 유효 솔리드, 외형 80×100×170mm(후크 제외) (depends: S1)
- [ ] S3. 1단 모델링 — 모듈 본체(상단 캐치 동일) + 뒷면 ㄷ자 클램프(개구 40mm) + 아래턱 암나사(피치 4mm) — 완료 기준: 유효 솔리드, 암나사 내경·피치가 나사 규격+공차와 일치 (depends: S2)
- [ ] S4. 썸스크류 모델링 — 완료 기준: 외경 18.5 / 피치 4 / 나사부 22mm ±0.1, 유효 솔리드 (depends: S1)
- [ ] S5. FCStd 저장 + STL 3개 내보내기 + 검증 리포트 — 완료 기준: DoD의 headless 검증 3항목 통과 출력 (depends: S2, S3, S4)
