# 출력 시간·필라멘트 절감 (품질 유지)

## 목표 / 비목표
- 목표: 8부품 전량 출력 기준 30시간이 걸리는 현재 상태에서, 형상 품질과 적층 강성을 유지한 채 **재료를 실측 기준으로 절반 이하로**, **출력 시간을 실측으로 확인 가능한 만큼** 줄인다. 모델 파라미터 변경 + 슬라이싱 설정 안내를 함께 산출한다.
- 비목표: 타공 확대(측정 결과 1% 절감뿐이라 기각), 강도 FEA 해석, 부품 인터페이스 재설계(스냅·클램프·서랍 레일 치수 불변), 다른 프린터·필라멘트 프로파일 튜닝, 부품 삭제.

## 그릴링에서 실측한 사실 (근거)
- 8부품 전량 = **1,066cm³ / 1,322g**. 이 중 `tier1`과 `tier1-drawer`는 **대체 부품**이고 `module2`/`module3`도 변형이라, 실사용 한 세트(1단서랍형+서랍+3칸+마감+나사)는 **601cm³ / 745g = 전량의 56%**.
- 벽 2.4 / 선반·바닥 3.0 으로 낮추면 세트가 **511cm³ (−15%)**, 검증 31항목 전부 통과. 이때도 필렛 r1.4·스냅 물림 1.55mm·앞턱 램프 53.5°가 유지됨(실측).
- 타공을 Ø6·피치 9.5로 키워도 벽 두께가 같으면 511 → 506cm³(**−1%**)뿐 → 기각.
- 사용자 3mf 설정 실측: 레이어 0.2 / 노즐 0.4 / wall_loops 2 / 인필 15% grid / **서포트 tree(auto) ON** / `support_on_build_plate_only=0` / 8개 플레이트.

## 확정 사양 (그릴링 합의)
- **모델**: `WALL` 3.0→**2.4**, `BOT_T` 4.0→**3.0**, `SHELF_T` 4.0→**3.0**. 클램프(`PLATE_T`/`JAW_T`)·스커트(`SKIRT_T`)·서랍 벽(`DRAWER_WALL`)·레일은 별도 파라미터라 **불변**.
- **호환성**: 벽 두께는 적층 인터페이스의 기준선이라, 2.4mm판은 기존 3.0mm판과 **섞어 쓸 수 없다**(구형 스커트가 좌우 각 0.85mm 헐거워지고 캐치 물림이 1.55→0.95mm로 감소). 호환을 포기하고 **문서에 경고를 명시**한다.
- **타공**: 현재 Ø4.5·피치 8.0 그대로.
- **슬라이싱 안내(문서 산출물)**: ① 실사용 세트만 출력(부품 선택 표) ② **서포트 OFF** — 뒷면 안착 방향에서 남는 하향면은 타공 구멍 상단 아치와 나사산뿐이고 둘 다 브리징 범위 ③ 레이어 0.2→**0.28** ④ 2.4mm 벽에서는 **wall_loops 3** 권장(벽이 솔리드로 차 강성을 회복, 갭 필 아티팩트 제거).
- **검증 강화**: 벽을 더 얇게 만들 때 조용히 깨지는 관계를 검증 항목으로 고정 — 스냅 돌기가 벽을 관통하지 않을 여유(`WALL − (BUMP_D − CLEAR) ≥ 0.5`)와 최소 물림(`BUMP_D − CLEAR ≥ 1.0`).
